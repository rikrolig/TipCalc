# Лабораторная работа №3 — TipCalc

## Задание
Калькулятор чаевых:
- 2 поля ввода: сумма счёта, количество блюд.
- Слайдер: чаевые 0–25%.
- 4 радиокнопки: скидка (выбирается программно).
- Расчёт итоговой суммы.

## Логика скидки
| Количество блюд | Скидка |
|-----------------|--------|
| 1–2 | 3% |
| 3–5 | 5% |
| 6–10 | 7% |
| > 10 | 10% |

## Тест-кейсы
| Сумма | Блюд | Чаевые | Итого |
|-------|------|--------|-------|
| 1000 | 2 | 10% | 1067.00 |
| 1000 | 4 | 10% | 1045.00 |
| 1000 | 10 | 10% | 1023.00 |
| 1000 | 15 | 10% | 990.00 |
